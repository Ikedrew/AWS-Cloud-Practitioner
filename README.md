# AWS-Cloud-Practitioner

📘 AWS Certified Cloud Practitioner – Practice Labs Completion
Description:
Completed the AWS Certified Cloud Practitioner training via Practice Labs, gaining foundational knowledge of core AWS services, cloud concepts, security, pricing, and architectural best practices. The hands-on labs provided practical experience with real AWS environments, reinforcing theoretical learning with applied skills.

Key Learning Outcomes:
- Understood the basic global infrastructure of AWS (Regions, Availability Zones, Edge Locations).
- Gained hands-on experience with services such as EC2, S3, IAM, RDS, and CloudWatch.
- Learned key concepts in cloud economics, billing models, and the AWS Shared Responsibility Model.
- Applied cloud security principles using IAM policies and best practices.
- Built confidence in navigating the AWS Management Console and interpreting documentation.

Tools & Skills Gained:
- AWS Management Console
- Identity and Access Management (IAM)
- Basic compute, storage, and networking services
- Cost and performance optimization fundamentals
- Hands-on lab environment via Practice Labs
